Context · Edge 英语阅读助手 1.0.0

1. 下载构建压缩包并全部解压到固定位置，例如 D 盘的 ContextEdge 文件夹。使用源码压缩包时也可直接使用其中的 dist 文件夹。
2. 在 Edge 地址栏打开 edge://extensions，启用「开发人员模式」，选择「加载解压缩的扩展」。
3. 选中 dist 文件夹。这一层应能直接看到 manifest.json。安装后请保留这个文件夹。
4. 从工具栏的扩展菜单打开 Context → 打开设置。填入个人 OpenAI API Key，确认模型名称后点击「保存设置」。默认模型为 gpt-6-luna，可改为你的项目有权访问且支持 Responses API 严格结构化输出的模型。真实查询的费用计入该 API 项目。
5. 刷新已经打开的英文网页，把鼠标指向正文中的一个单词，轻按左 Ctrl。安装后新打开的普通网页会自动启用。更新构建时，在扩展管理页点击 Context 的「重新加载」，然后刷新阅读页面。

查短语时，在同一段中先拖选英文，再右键点「用 Context 解释」。滚动原文时，卡片跟着所查的词或短语移动。原词滚出可见区域时卡片暂时隐藏，滚回来就能继续看。按 Esc 或点击卡片外可关闭。

先体验下划线时，可以直接用 Edge 打开解压后的 dist/options.html，或在扩展设置中找到「查词试玩」。指向 pitch 轻按左 Ctrl 直接看释义。按 Esc 收起，再双击 fundraising，想看释义时点回这个词或它的笔画。试玩使用本地示例，无需 API Key。

在普通英文网页上，双击正文单词会立即画线并开始查询。可以先标多个词再逐个点开，切换标签页回来仍能查看。按 Esc 或点空白只收起卡片，刷新或离开文章时清除标记。阅读设置中可关闭「双击预查」，或在自动、灰蓝、陶土三种笔色设置之间切换。自动模式按原词底色选色，浅底灰蓝、深底陶土。

卡片优先在原词上方打开，长释义可在卡片内滚动。原词太靠近窗口顶端时，卡片会移到下方。拖动窗口边缘时，卡片继续贴着原词，只有宽度放不下时才收窄换行。

按住 Ctrl 滚动鼠标滚轮可调整页面缩放。100% 时卡片宽 420 px、英文正文为 17 px。页面放大至 125% 时，卡片看起来约宽 462 px。放大至 150% 或更高时，卡片最多约宽 504 px，正文约为 20.4 px。按 Ctrl+0 即可恢复正常大小，低于 100% 时卡片随页面自然缩小。缩放时可以继续阅读同一张卡片并使用喇叭。

点击标题旁的喇叭听英语发音，也可以用 Tab 聚焦后按 Enter 或空格。等待释义时可以听原词，标题变为短语时可以听完整短语。播放结束后可再次点击。发音使用 Edge 提供的英语语音，选用在线语音时需要联网。

密钥只存于当前配置文件，不同步，没有独立加密。首次真实查词时扩展将所选词句和邻近上下文发送到 OpenAI 官方 API。真实查询使用你自己的项目额度。

轻点左 Ctrl 并松开即可查词。首次查询时，英文解释和中文释义会随模型返回分行显示。同一语境命中缓存时会直接显示完整卡片。

本次更新已用模拟 API 在 Chromium 和 Windows 正式版 Edge 验证。线上生成速度取决于网络和模型。
