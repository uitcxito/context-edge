start = 3     end = 8

start 从 0 数，end 指向最后一个字母之后的位置。这里取原句第 3 到第 8 位之前，正好是 pitch。同一句里即使有两个 pitch，也可以区分你指的那一个。

这段代码做了什么

lookup 表示「查词」。id 给这次查询编号，reading 装选词、原句和位置，preload 标记是否提前查询。

直接查词时 preload 为 false。浏览器把这条消息转交给扩展后台；原词的屏幕坐标留在网页。
