解释怎样回到刚才的 pitch？

模型交回的是文字。把这段文字放进正确的卡片，还需要后台验收、网页认领。

从一段段文字到两行释义

像陆续收到一封信的几页。后台把片段接起来，先检查目标词是否确实覆盖你指的那一次，再挑出已经写完整的释义。

① 等待

网页先显示 pitch 和「正在读取语境…」。后台目前可能还在等模型的第一段文字。

② 预览

目标正确，完整的英文字段通过检查后，后台可先送回英文。中文字段完整并通过检查后再补上；两行也可能一起到达。

③ 完成

收到完成事件，后台重新校验整份结果，尝试写缓存，再交回最终答复。如果有英文补充，卡片会显示 More。

哪张卡片可以收这条预览？

后台给预览附上原来的查询编号，发回发起查询的网页文档。网页脚本按编号找到词的标记，把新内容交给当前展开的卡片。

preview(id: string, result: ExplanationPreview) {

  if (!mark || mark.reply) return;

  if (this.opened?.mark === mark) this.opened.card.showMeanings(result);
}
